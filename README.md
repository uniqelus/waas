# waas

Workflow-as-a-Service is a set of Kubernetes CRDs and operators for managing serverless, event-driven data-processing pipelines

## Features

* **Kubernetes-Native:** Declarative management of serverless functions and workflows using CRDs and operators.
* **Workflow Orchestration:** Managed data-processing pipelines powered by Argo Workflows.
* **Event-Driven Execution:** Trigger functions and workflows in response to application events.
* **Application Packaging:** Organize functions, events, entities, and workflows into reusable packages.
* **Serverless Computing:** Containerized function execution with automatic scaling and resource isolation.
* **GitOps Integration:** Manage applications and workflows using version-controlled Kubernetes manifests.
